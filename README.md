 # Game of Life

A simple implementation of Conway’s Game of Life.

- `main.rs` starts and runs the game.
- `grid.rs` manages the cell grid and its simulation.

## Controls

- Press **Space** to pause or unpause the game.
- While paused, click a cell to switch it between alive and dead.
